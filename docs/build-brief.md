이 서비스는 선택형 투자 리스크 진단 웹앱입니다.
사용자가 자유롭게 긴 질문을 입력하는 AI 챗봇이 아니라, 몇 가지 선택형 질문에 답하면 현재 투자 리스크 상태와 먼저 확인해야 할 기준을 차분하게 정리해주는 구조예요.

핵심 방향:
- 초기 MVP는 `투자 리스크 진단` 하나만 구현
- 외부 연결은 `머니플로우레이더`만 우선 반영
- `케어링크` 연결은 이번 범위에서 제외
- 톤은 딱딱한 다나까체가 아니라 `요/죠`체 기반의 부드러운 심리 정리형
- 사용자를 탓하지 않고, 투자 조언처럼 직접 지시하지 않기
- 차분한 금융 리서치 사이트 느낌
- 과한 애니메이션, 게임형 UI, 공포 마케팅 느낌은 피하기

구현 범위:
- `/` 랜딩페이지
- `/diagnosis/investment-risk` 질문 플로우 페이지
- `/diagnosis/investment-risk/result` 결과 페이지
- 6개 질문 데이터 분리
- 리스크 계산 로직
- 심리 태그 기반 결과 문구
- 관련 콘텐츠 3개 추천
- 결과 복사 기능
- 다시 진단하기 기능

기술 방향:
- Next.js 기반
- 최신 Next.js 문서 기준으로 구현
- Tailwind CSS 사용 가능
- 데이터는 하드코딩하지 말고 분리된 파일로 관리
- MVP는 DB 없이 구현
- 모바일 우선 반응형

질문/결과/콘텐츠 구조:
- 질문 데이터, 결과 템플릿, 심리 태그 문구, 관련 콘텐츠 데이터는 별도 파일로 분리
- 과한 추상화는 피하고 MVP에 필요한 최소 구조로 구현

랜딩 메인 카피:
- 리스크체크
- by 금융리스크랩
- 지금 판단이 어려운 건, 정보가 부족해서만은 아닐 수 있어요.
- 손실, 물타기, 레버리지, 반대매매처럼 복잡한 투자 상황에서는 무엇을 먼저 확인해야 하는지부터 정리하는 게 중요해요.
- 몇 가지 질문에 답하면, 현재 리스크 상태와 지금 먼저 확인해야 할 기준을 차분하게 정리해드려요.
- CTA: 내 투자 리스크 진단하기
- 주의 문구: 이 서비스는 투자 조언이 아니라, 현재 상황을 차분히 정리해보기 위한 리스크 체크 도구예요.

질문 플로우:
Q1. 지금 가장 가까운 상황은 어떤 쪽인가요?
Q2. 지금 마음 상태는 어떤 쪽에 더 가까우세요?
Q3. 현재 투자 구조는 어떤 쪽에 가까우세요?
Q4. 현재 손실 수준은 어느 정도로 느껴지세요?
Q5. 지금 대응할 수 있는 여력은 어느 정도 있으세요?
Q6. 지금 가장 알고 싶은 건 무엇인가요?

리스크 결과 구간:
- stable: 안정 구간
- caution: 주의 구간
- risk: 손실 확대 위험 구간
- high_risk: 강한 리스크 경고 구간

결과 화면 포함 요소:
1. 리스크 단계
2. 현재 상황 요약
3. 심리 태그 기반 추가 문구
4. 가장 조심해서 봐야 할 부분
5. 지금은 피하는 게 좋은 행동
6. 먼저 확인해야 할 기준
7. 관련 콘텐츠 3개
8. 머니플로우레이더 연결 버튼
9. 결과 요약 복사 버튼
10. 다시 진단하기 버튼

머니플로우레이더 연결 섹션 문구:
- 제목: 내 상황을 정리했다면, 시장 흐름도 함께 보는 게 좋아요.
- 본문: 투자 리스크는 내 판단만의 문제가 아니라, 지금 시장이 어떤 흐름인지와도 연결돼 있어요. 주요 테마와 자금 흐름은 머니플로우레이더에서 이어서 확인해보세요.
